真正开始做博客之后，我才发现第一版最重要的不是功能多，而是先把站点跑起来、文章发出去、链接能分享给别人。

<!-- more -->

我最后选择 `Hexo + GitHub Pages`，主要是因为这套组合足够轻：

- 写文章只需要 Markdown
- 站点生成速度快
- 可以直接托管到 GitHub
- 后面想换主题或者继续接评论系统也不难

对个人博客来说，这种“先发布，再慢慢迭代”的节奏很舒服。你不用一开始就准备数据库、后台管理系统和复杂权限，只需要专注在内容本身。

这一版站点里，我最希望保留下来的感觉是：

1. 首页足够清爽，第一次打开就能知道这是一个人的个人站。
2. 文章页要好读，目录、标签、归档这些结构要清楚。
3. 部署过程最好自动化，避免每次更新都手动上传文件。

等这些都稳定下来，再去加评论、搜索优化、统计或更复杂的内容结构，会轻松很多。
